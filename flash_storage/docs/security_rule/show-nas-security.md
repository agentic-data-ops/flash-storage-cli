# show nas security


##### Function

The **show nas security** command is used to query the security rules of the NAS protocol.

##### Format

**show nas security**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query NAS security rules.

```text
admin:/>show nas security
Ntlm Level : 3
```

##### System Response

The following table describes the parameter meanings.

| Parameter  | Meaning                             |
|------------|-------------------------------------|
| Ntlm Level | NTLM identity authentication level. |
