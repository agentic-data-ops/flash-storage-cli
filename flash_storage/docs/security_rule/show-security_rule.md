# show security_rule


##### Function

The **show security_rule** command is used to query the information about security rules. Security rules are used to control the access of the storage system by maintenance terminals.Only the maintenance terminals in the security rules can access the storage system.

##### Format

**show security_rule**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query information about security rules.

```text
admin:/>show security_rule

Enabled
-------
No
```

##### System Response

None
