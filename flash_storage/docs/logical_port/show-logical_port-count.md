# show logical_port count


##### Function

The **show logical_port count** command is used to query the count of logical ports in the system.

##### Format

**show logical_port count**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the number of all logical ports.

```text
admin:/>show logical_port count

Logical Port Number : 6
```

##### System Response

The following table describes the parameter meanings.

| Parameter           | Meaning                  |
|---------------------|--------------------------|
| Logical Port Number | Number of logical ports. |
