# change service ndmp_reset_password


##### Function

The **change service ndmp_reset_password** command is used to reset the NDMP password.

##### Format

**change service ndmp_reset_password**

##### Parameters

None

##### Usage Guidelines

This command is not supported in this version, and the command output is invalid.

OceanStor Dorado 18000 V6, Dorado 5000 V6, Dorado 6000 V6 and Dorado 8000 V6 storage systems support this command.

##### Example

Reset the NDMP password.

```text
admin:/>change service ndmp_reset_password
Password:*************
Reenter password:*************
Command executed successfully
```

##### System Response

None
