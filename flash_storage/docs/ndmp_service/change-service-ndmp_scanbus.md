# change service ndmp_scanbus


##### Function

The **change service ndmp_scanbus** command is used to execute the scanbus command.

##### Format

**change service ndmp_scanbus**

##### Parameters

None

##### Usage Guidelines

OceanStor Dorado 18000 V6, Dorado 5000 V6, Dorado 6000 V6 and Dorado 8000 V6 storage systems support this command.

##### Example

Execute the "scanbus" command.

```text
admin:/>change service ndmp_scanbus
Command executed successfully.
```

##### System Response

None
