# show performance statistic_enabled


##### Function

The **show performance statistic_enabled** command is used to query the status of the performance statistics switch.

##### Format

**show performance statistic_enabled**

##### Parameters

None

##### Usage Guidelines

None

##### Example

To query the status of the system performance statistics switch, run the following command:

```text
admin:/>show performance statistic_enabled

Statistic Enabled : Yes
```

##### System Response

The following table describes the parameter meanings.

| Parameter         | Meaning                                      |
|-------------------|----------------------------------------------|
| Statistic Enabled | Status of the performance statistics switch. |
