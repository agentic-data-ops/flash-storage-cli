# change performance statistic_enabled


##### Function

The **change performance statistic_enabled** command is used to configure the performance statistics switch. Run this command to enable or disable the performance statistics function.

##### Format

**change performance statistic_enabled** enabled=?

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| enabled=? | Switch of the performance statistical function. | The value can be "yes" or "no", where: <br>"yes": The performance statistics function will be enabled.<br>"no": The performance statistics function will be disabled. |

##### Usage Guidelines

None

##### Example

To enable the performance statistics function for the storage system, run the following command:

```text
admin:/>change performance statistic_enabled enabled=yes
Command executed successfully.
```

##### System Response

None
