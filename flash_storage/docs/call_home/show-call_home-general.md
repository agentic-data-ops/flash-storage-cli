# show call_home general


##### Function

The **show call_home general** command is used to query information about Call Home functions.

##### Format

**show call_home general**

##### Parameters

None

##### Usage Guidelines

This command is used to query information about Call Home functions, including the function switch and registration information.

##### Example

Query information about Call Home functions.

```text
admin:/>show call_home general
Switch Status    : Off
Is Authenticated : Yes
```

##### System Response

The following table describes the parameter meanings.

| Parameter        | Meaning                                               |
|------------------|-------------------------------------------------------|
| Switch Status    | Switch status.                                        |
| Is Authenticated | Whether the Call Home service has been authenticated. |
