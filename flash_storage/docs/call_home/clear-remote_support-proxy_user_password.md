# clear remote_support proxy_user_password


##### Function

The **clear remote_support proxy_user_password** command is used to clear the user name and password of the eService proxy server.

##### Format

**clear remote_support proxy_user_password**

##### Parameters

None

##### Usage Guidelines

This command is used to clear the user name and password of the eService proxy server.

##### Example

Clear the user name and password of the Call Home proxy server.

```text
admin:/>clear remote_support proxy_user_password
Command executed successfully.
```

##### System Response

None
