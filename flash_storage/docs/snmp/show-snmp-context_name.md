# show snmp context_name


##### Function

The **show snmp context_name** command is used to query the Simple Network Management Protocol (SNMP) context name of the storage system.

##### Format

**show snmp context_name**

##### Parameters

None

##### Usage Guidelines

None.

##### Example

To query the SNMP context name of the storage system, run the following command:

```text
admin:/>show snmp context_name

Context Name : Array
```

##### System Response

The following table describes the parameter meanings.

| Parameter    | Meaning                                                 |
|--------------|---------------------------------------------------------|
| Context Name | Simple Network Management Protocol (SNMP) context name. |
