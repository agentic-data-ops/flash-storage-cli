# show snmp port


##### Function

The **show snmp port** command is used to query the port number of the SNMP service.

##### Format

**show snmp port**

##### Parameters

None

##### Usage Guidelines

None.

##### Example

Query the port number of the SNMP service.

```text
admin:/>show snmp port
SNMP Listening Port : 161
```

##### System Response

The following table describes the parameter meanings.

| Parameter           | Meaning                          |
|---------------------|----------------------------------|
| SNMP Listening Port | Port number of the SNMP service. |
