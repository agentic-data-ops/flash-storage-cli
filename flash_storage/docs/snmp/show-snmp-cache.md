# show snmp cache


##### Function

The **show snmp cache** command is used to show the current SNMP cache object.

##### Format

**show snmp cache**

##### Parameters

None

##### Usage Guidelines

This command can be executed to show the existing SNMP cache objects.

##### Example

Show the current SNMP cache object.

```text
admin:/>show snmp cache
object type
-----------
LUN
FC
PCIE
```

##### System Response

The following table describes the parameter meanings.

| Parameter   | Meaning                 |
|-------------|-------------------------|
| object type | Name of a cache object. |
