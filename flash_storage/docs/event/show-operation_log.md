# show operation_log


##### Function

The change operation_log command is used to query the retention policy of operation logs.

##### Format

**show operation_log**

##### Parameters

None

##### Usage Guidelines

None.

##### Example

Query the retention days of operation logs.

```text
admin:/>show operation_log
Retention Days : 90
```

##### System Response

The following table describes the parameter meanings.

| Parameter      | Meaning                           |
|----------------|-----------------------------------|
| Retention Days | Retention days of operation logs. |
