# show domain ad_prefdc


##### Function

The **show domain ad_prefdc** command is used to check the configuration of the preferred domain controller.

##### Format

**show domain ad_prefdc**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Check the configuration of the preferred domain controller.

```text
admin:/>show domain ad_prefdc
Domain Controller Name : testname
```

##### System Response

The following table describes the parameter meanings.

| Parameter              | Meaning                                  |
|------------------------|------------------------------------------|
| Domain Controller Name | Name of the preferred domain controller. |
