# show user_mode enabled


##### Function

The **show user_mode enabled** command is used to query the supported views.

##### Format

**show user_mode enabled**

##### Parameters

None

##### Usage Guidelines

This command can be executed only when SNMP is running correctly.

##### Example

Query the supported views.

```text
admin:>show user_mode enabled
Developer View: Enabled
```

##### System Response

The following table describes the parameter meanings.

| Parameter      | Meaning         |
|----------------|-----------------|
| Developer View | Developer view. |
