# show lun_migration count


##### Function

The **show lun_migration count** command is used to calculate the number of migrated LUNs.

##### Format

**show lun_migration count**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Calculate the number of migrated LUNs.

```text
admin:/>show lun_migration count

LUN Migration Count : 1
```

##### System Response

The following table describes the parameter meanings.

| Parameter           | Meaning                        |
|---------------------|--------------------------------|
| LUN Migration Count | Number of LUN migration tasks. |
