# delete role general


##### Function

The **delete role general** command to used to delete roles.

##### Format

**delete role general** id=?

##### Parameters

| Parameter | Description                                           | Value                                                    |
|-----------|-------------------------------------------------------|----------------------------------------------------------|
| id=?      | Role ID. The value must be an integer from 1 to 1023. | To obtain the value, run the "show role system" command. |

##### Usage Guidelines

None.

##### Example

Delete the role whose ID is "65".

```text
admin:/>delete role general id=65
Command executed successfully.
```

##### System Response

None
