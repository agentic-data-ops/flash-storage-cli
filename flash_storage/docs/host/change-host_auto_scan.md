# change host_auto_scan


##### Function

The **change host_auto_scan** command is used to enable or disable the automatic scan function of a host.

##### Format

**change host_auto_scan** switch=?

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| switch=? | Indicates to enable or disable the automatic scan function. | The value can be "on" or "off", where <br>"on": to enable the function.<br>"off": to disable the function. |

##### Usage Guidelines

None

##### Example

To enable the automatic scan function, run the following command:

```text
admin:/>change host_auto_scan switch=on
Command executed successfully.
```

To disable the automatic scan function, run the following command:

```text
admin:/>change host_auto_scan switch=off
Command is executable now.
```

##### System Response

None
