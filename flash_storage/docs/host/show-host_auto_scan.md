# show host_auto_scan


##### Function

The **show host_auto_scan** command is used to check whether the automatic scan of a host is enabled.

##### Format

**show host_auto_scan**

##### Parameters

None

##### Usage Guidelines

On the CLI, run the **show host_auto_scan** command to check whether the automatic scan function of the host is enabled.

##### Example

To check whether the automatic scan function of a host is enabled, run the following command:

```text
admin:/>show host_auto_scan

Auto-Scan Switch
----------------
Off
```

##### System Response

The following table describes the parameter meanings.

| Parameter        | Meaning                                              |
|------------------|------------------------------------------------------|
| Auto-Scan Switch | Indicates the switch of the automatic scan function. |
