# scan host


##### Function

The **scan host** command is used to scan for application servers where UltraPath is installed.

##### Format

**scan host**

##### Parameters

None

##### Usage Guidelines

After this command is executed, logical connections are automatically set up between application servers where UltraPath is installed and the storage system.

##### Example

Scan for application servers whose physical connections have been set up.

```text
admin:/>scan host
Command executed successfully.
```

##### System Response

None
