# show recycle_bin_policy general


##### Function

The **show recycle_bin_policy general** command is used to query the recycle bin configuration policy.

##### Format

show recycle_bin_policy genera

##### Parameters

None

##### Usage Guidelines

Run the "**show recycle_bin_policy general**" command to query the recycle bin configuration policy.

##### Example

Query the recycle bin configuration policy.

```text
admin:/>show recycle_bin_policy general

Delay Delete Enable          : No
Delay Delete Interval(hours) : 24

```

##### System Response

The following table describes the parameter meanings.

| Parameter             | Meaning                              |
|-----------------------|--------------------------------------|
| Delay Delete Enable   | Whether delayed deletion is enabled. |
| Delay Delete Interval | Delayed deletion interval.           |
