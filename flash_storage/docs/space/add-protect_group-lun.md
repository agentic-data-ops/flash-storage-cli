# add protect_group lun


##### Function

The **add protect_group lun** command is used to add a member LUN to a specified protection group.

##### Format

**add protect_group lun** protect_group_id=? lun_id_list=? \[ async_replication_remote_id_1=? \[ async_replication_remote_id_2=? \| sync_replication_remote_id=? \| hyper_metro_remote_id=? \] \]

**add protect_group lun** protect_group_id=? lun_id_list=? \[ sync_replication_remote_id=? \[ async_replication_remote_id_1=? \] \]

**add protect_group lun** protect_group_id=? lun_id_list=? \[ hyper_metro_remote_id=? \[ async_replication_remote_id_1=? \] \]

**add protect_group lun** protect_group_id=? lun_id_list=? \[ remote_name_rule=? \[ name_suffix=? \| name_prefix=? \] \]

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| protect_group_id=? | Protection group ID. | To obtain the value, run the "show protect_group general" command. |
| lun_id_list=? | ID list of LUNs added to a protection group. | You can run the "show lun general" command to obtain the LUN ID list. When you need to add multiple LUNs to a protection group: <br>IDs of multiple LUNs can be separated by commas (,). For example, lun_id_list=1,2,3,4,5.<br>You can specify LUN ID ranges separated by hyphens (-). For example, lun_id_list=1-5,7,9-11.<br>A maximum of 100 LUN IDs can be specified at a time. |
| async_replication_remote_id_1=? | First ID of the remote device for which an asynchronous remote replication pair is created. | To obtain the value, run the "show remote_device general" command on local device. |
| async_replication_remote_id_2=? | Second ID of the remote device for which an asynchronous remote replication pair is created. | To obtain the value, run the "show remote_device general" command on local device. |
| sync_replication_remote_id=? | ID of the remote device for which a synchronous remote replication pair is created. | To obtain the value, run the "show remote_device general" command on local device. |
| hyper_metro_remote_id=? | ID of the remote device for which a HyperMetro pair is created. | To obtain the value, run the "show remote_device general" command on local device. |
| remote_name_rule | Naming rule of the remote end. | The options are as follows: <br>automatically_generated: The value is automatically generated by the system.<br>same_as_locally: consistent with the local end.<br>user_defined: user-defined. |
| name_suffix | User-defined name suffix. This parameter is valid only when remote_name_rule=? is set to "user_defined". | The value contains 1 to 16 ASCII characters, including digits, letters, underscores (_), hyphens (-), and periods (.). |
| name_prefix | User-defined name prefix. This parameter is valid only when remote_name_rule=? is set to "user_defined". | The value contains 1 to 32 ASCII characters, including digits, letters, underscores (_), hyphens (-), and periods (.), and must start with a digit or letter. |

##### Usage Guidelines

-   A LUN can be added to a maximum of eight protection groups.
-   A maximum of 4096 LUNs can be added to a protection group.

##### Example

Add LUN "2" to protection group "2".

```text
admin:/>add protect_group lun protect_group_id=2 lun_id_list=2
Add LUN to PG or LUN Group (pgName) in background.
Run the "show task general task_id=2" command to query the execution result.
```

##### System Response

None
