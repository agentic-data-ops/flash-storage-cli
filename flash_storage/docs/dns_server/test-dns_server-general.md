# test dns_server general


##### Function

The **test dns_server general** command is used to test the connectivity of a DNS server.

##### Format

**test dns_server general** address=?

##### Parameters

| Parameter | Description                   | Value                                       |
|-----------|-------------------------------|---------------------------------------------|
| address=? | IP address of the DNS server. | Both IPv4 and IPv6 addresses are supported. |

##### Usage Guidelines

None

##### Example

Test the connectivity of the DNS server whose IP address is "10.148.105.124".

```text
admin:/>test dns_server general address=10.148.105.124
Command executed successfully.
```

##### System Response

None
