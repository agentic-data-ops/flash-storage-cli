# show disk routine_test


##### Function

The **show disk routine_test** command is used to query the status and period of a routine disk test.

##### Format

**show disk routine_test**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the status and period of a routine disk test.

```text
admin:/>show disk routine_test

Enable Routine Test :  On
Routine Test Period :  60Minutes
```

##### System Response

The following table describes the parameter meanings.

| Parameter           | Meaning                          |
|---------------------|----------------------------------|
| Enable Routine Test | Status of the routine disk test. |
| Routine Test Period | Period of the routine disk test. |
