# show disk precopy


##### Function

The **show disk precopy** command is used to query the status of the disk precopy function.

##### Format

**show disk precopy**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the status of the disk precopy function.

```text
admin:/>show disk precopy

PreCopy Enabled : Yes
```

##### System Response

The following table describes the parameter meanings.

| Parameter       | Meaning                              |
|-----------------|--------------------------------------|
| PreCopy Enabled | Status of the disk precopy function. |
