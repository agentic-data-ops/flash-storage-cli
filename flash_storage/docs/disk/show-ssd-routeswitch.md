# show ssd routeswitch


##### Function

The **show ssd routeswitch** command is used to query the status of a routine SSD test.

##### Format

**show ssd routeswitch**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the status of a routine SSD test.

```text
admin:/>show ssd routeswitch

SSD Route Switch : Off
```

##### System Response

The following table describes the parameter meanings.

| Parameter        | Meaning                                                                            |
|------------------|------------------------------------------------------------------------------------|
| SSD Route Switch | Status of a routine SSD test. The value can be "on" (enabled) or "off" (disabled). |
