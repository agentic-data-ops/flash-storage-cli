# change ssd routeswitch


##### Function

The **change ssd routeswitch** command is used to set the status of a routine SSD test.

##### Format

**change ssd routeswitch** ssd_route_switch=?

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| ssd_route_switch=? | Status of a routine SSD test. | The value can be "on" or "off", where: <br>"on": The routine SSD test is enabled.<br>"off": The routine SSD test is disabled. |

##### Usage Guidelines

None

##### Example

Set the status of a routine SSD test to "off".

```text
admin:/>change ssd routeswitch ssd_route_switch=off
Command executed successfully.
```

##### System Response

None
