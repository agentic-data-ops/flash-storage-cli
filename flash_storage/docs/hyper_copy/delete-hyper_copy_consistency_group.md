# delete hyper_copy_consistency_group


##### Function

The **delete hyper_copy_consistency_group** command is used to delete a HyperCopy consistency group.

##### Format

**delete hyper_copy_consistency_group** hyper_copy_consistency_group_id_list=?

##### Parameters

| Parameter                            | Description                          | Value                                                                 |
|--------------------------------------|--------------------------------------|-----------------------------------------------------------------------|
| hyper_copy_consistency_group_id_list | HyperCopy consistency group ID list. | To obtain the value, run "show hyper_copy_consistency_group general". |

##### Usage Guidelines

None

##### Example

Delete HyperCopy consistency group "7".

```text
admin:/>delete hyper_copy_consistency_group hyper_copy_consistency_group_id_list=7
Delete HyperCopy consistency group 7 successfully.
```

##### System Response

None
