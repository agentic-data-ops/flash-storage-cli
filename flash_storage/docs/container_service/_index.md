# container_service

Manage container services, including activation, deployment, and configuration.

| command | function |
|---|---|
| add container_service general | add container service resources. |
| change container_service active | activate the container service for the first time. |
| change container_service general | change the status of a container service. |
| create container_service general | create container service resources. |
| show container_service general | query container service information. |
