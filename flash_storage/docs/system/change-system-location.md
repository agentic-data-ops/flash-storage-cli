# change system location


##### Function

The **change system location** command is used to change the geographical location of a storage system.

##### Format

**change system location** location=?

##### Parameters

| Parameter  | Description                             | Value                                   |
|------------|-----------------------------------------|-----------------------------------------|
| location=? | Updated location of the storage system. | The value contains 1 to 511 characters. |

##### Usage Guidelines

When the location of a storage system is incorrect, you can run this command to modify the location.

##### Example

Change the location of the storage system to "headquarters".

```text
admin:/>change system location location=headquarters
Command executed successfully.
```

##### System Response

None
