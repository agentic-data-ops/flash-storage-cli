# change system name


##### Function

The **change system name** command is used to change the storage system's name.

##### Format

**change system name** name=?

##### Parameters

| Parameter | Description                         | Value                                                                                                             |
|-----------|-------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| name=?    | Updated name of the storage system. | The value contains 1 to 127 characters including digits, letters, underscores (\_), hyphens (-), and periods (.). |

##### Usage Guidelines

The "**change system name** name=?" command is executed to change the storage system's name.

##### Example

Change the storage system's name to "newsystem".

```text
admin:/>change system name name=newsystem
Command executed successfully.
```

##### System Response

None
