# show system manufactory


##### Function

The **show system manufactory** command is used to query the vendor and brand of the storage system.

##### Format

**show system manufactory**

##### Parameters

None

##### Usage Guidelines

None.

##### Example

Query the vendor and brand of the storage system.

```text
admin:/>show system manufactory

Vendor : huawei
Brand : OceanStor
Model : XXXX
```

##### System Response

The following table describes the parameter meanings.

| Parameter | Meaning     |
|-----------|-------------|
| Vendor    | The vendor. |
| Brand     | The brand.  |
| Model     | The model.  |
