# show bst enabled


##### Function

The **show bst enabled** command is used to display the global BST function.

##### Format

**show bst enabled**

##### Parameters

None

##### Usage Guidelines

The **show bst enabled** command is used to display the global BST function.

##### Example

Display the global BST function.

```text
admin:/>show bst enabled

Enabled : No
```

##### System Response

The following table describes the parameter meanings.

| Parameter | Meaning                                                                                          |
|-----------|--------------------------------------------------------------------------------------------------|
| Enabled   | Yes: The global BST function of LUNs is enabled.No: The global BST function of LUNs is disabled. |
