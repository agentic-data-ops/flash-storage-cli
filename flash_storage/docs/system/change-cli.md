# change cli


##### Function

The **change cli** command is used to modify command line interface (CLI) settings. Use this command when you need to modify the CLI timeout period, capacity display mode, output paging mode, command execution confirmation switch, or performance statistics display mode.

##### Format

**change cli** { timeout=? \| capacity_mode=? \| more_enabled=? \| silent_enabled=? \| monitor_style=? \| separator=? } \*

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| timeout=? | CLI timeout period. You will be automatically logged out of the CLI if you have not used it for the set period. | The value ranges from 1 to 100, expressed in minutes. The default value of the system is 30 minutes. The parameter value range cannot exceed the session timeout period of the storage system, run the "show safe_strategy" command to query this period. |
| capacity_mode=? | Capacity display mode. This parameter affects the output of any storage capacity-associated commands such as "show disk general". | The value can be "automatic" or "precise", where: <br>"automatic": The capacity unit will be automatically adjusted in the output. This option can automatically adjust the capacity unit in the output when the output contains a relative great capacity. For example, this option can display "1024 KB" as "1 MB" in the output.<br>"precise": The capacity unit in the output remains the same as the exact unit generated by the storage system.<br> The default value is "automatic". |
| more_enabled=? | Whether or not to automatically split the output that spans multiple screens. | The value can be "yes" or "no", where: <br>"yes": When the output spans more than one screen, screen scrolling is deactivated and pressing any key scrolls to the next screen.<br>"no": The automatic output paging function will be disabled.<br> The default value is "yes". |
| silent_enabled=? | Whether or not to display the confirmation message and output for a command that you have just executed. | The value can be "yes" or "no", where: <br>"yes": No confirmation message and output are displayed for the command that you have just executed. This option is normally used to mask the output for a script that you have executed.<br>"no": The confirmation message and output are displayed for the command that you have just executed.<br> The default value is "no". |
| monitor_style=? | Performance statistics display mode. This parameter determines the display mode of all performance statistics commands such as "show performance lun". | The value can be "steady" or "scroll", where: <br>"steady": to display performance statistics by steady mode.<br>"scroll": to display performance statistics by scrolling mode.<br> The default value is "steady". |
| separator | Command output list separator. | The value can be any character. |

##### Usage Guidelines

-   To set a CLI timeout period, run **change cli** timeout=?.
-   To set a capacity display mode, run **change cli** capacity_mode=?.
-   To enable or disable the automatic output paging function, run **change cli** more_enabled=?.
-   To display or mask the confirmation message and output for a command that you have just executed, run **change cli** silent_enabled=?.
-   To set the performance statistics display mode, run **change cli** monitor_style=?.
-   To set a command output list separator, run "**change cli** separator=?".
-   This command is valid only for the current command window. You need to reset in other command windows.

##### Example

Set the CLI timeout period to "60" minutes.

```text
admin:/>change cli timeout=60
Command executed successfully.
```

Enable the CLI to automatically adjust the capacity unit in the output.

```text
admin:/>change cli capacity_mode=automatic
Command executed successfully.
```

Disable the automatic output paging function.

```text
admin:/>change cli more_enabled=no
Command executed successfully.
```

Mask the confirmation message and output for a command that you have just executed.

```text
admin:/>change cli silent_enabled=yes
Command executed successfully.
```

Set the performance statistics display mode to steady.

```text
admin:/>change cli monitor_style=steady
Command executed successfully.
```

Set "%" as the command output list separator.

```text

admin:/>change cli separator=%

Command executed successfully.

```
