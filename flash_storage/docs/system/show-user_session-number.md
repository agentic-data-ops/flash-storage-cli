# show user_session number


##### Function

The **show user_session number** command is used to show the number of sessions supported by the system.

##### Format

**show user_session number**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the number of sessions in the system.

```text
admin:/>show user_session number
Session Number : 32
```

##### System Response

The following table describes the parameter meanings.

| Parameter      | Meaning                                     |
|----------------|---------------------------------------------|
| Session Number | Number of sessions supported by the system. |
