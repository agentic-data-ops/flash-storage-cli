# show system power_consumption


##### Function

The **show system power_consumption** command is used to query system power consumption in real time.

##### Format

**show system power_consumption**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query system power consumption in real time.

```text
admin:/>show system power_consumption
Power Consumption value(W) :10
```

##### System Response

The following table describes the parameter meanings.

| Parameter               | Meaning                   |
|-------------------------|---------------------------|
| Power Consumption value | System power consumption. |
