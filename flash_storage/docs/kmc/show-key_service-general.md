# show key_service general


##### Function

The **show key_service general** command is used to query the key service configuration.

##### Format

**show key_service general**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the key service configuration.

```text
admin:/>show key_service general
Service Type : KMS
```

##### System Response

The following table describes the parameter meanings.

| Parameter    | Meaning           |
|--------------|-------------------|
| Service Type | Key service type. |
