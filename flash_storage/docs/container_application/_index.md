# container_application

Manage container applications, including deployment, configuration, and query.

| command | function |
|---|---|
| change container_application general | update an application. |
| change container_application view | enter the container OS. |
| create container_application general | deploy an application. |
| delete container_application general | delete an application. |
| show container_application dynamic_config | query the configuration items that can be configured for deploying a chart package. |
| show container_application general | query the list of available chart packages or the list or details of deployed applications. |
