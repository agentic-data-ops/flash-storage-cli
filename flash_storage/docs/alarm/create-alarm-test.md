# create alarm test


##### Function

The **create alarm test** command is used to simulate the reporting of fault alarm.

##### Format

**create alarm test**

##### Parameters

None

##### Usage Guidelines

-   This command is used to test the alarm reporting function of the device. After the test is complete, clear the alarm reported during the test.
-   This command is used to report a specific fault alarm. If this fault alarm already exists, the newly reported fault alarm will be invalid.

##### Example

To simulate the reporting of fault alarm.

```text
admin:/>create alarm test
Send test alarm successfully.
```

##### System Response

None
