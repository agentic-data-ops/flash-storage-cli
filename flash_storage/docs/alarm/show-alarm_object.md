# show alarm_object


##### Function

The **show alarm_object** command is used to query alarm object information.

##### Format

**show alarm_object**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query alarm object information.

```text
admin:/>show alarm_object
ID  Alarm Object Type  Alarm Object Name
--  -----------------  -----------------
0   6                  port
1   10                 disk
2   11                 LUN
```

##### System Response

The following table describes the parameter meanings.

| Parameter         | Meaning            |
|-------------------|--------------------|
| ID                | ID.                |
| Alarm Object Type | Alarm object type. |
| Alarm Object Name | Alarm object name. |
