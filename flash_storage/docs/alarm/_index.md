# alarm

Manage alarms and event notifications, including notification receivers, SMTP servers, alarm masking, and event configuration.

| command | function |
|---|---|
| add notification receiver | add email addresses or phone numbers used to receive alarm or event notifications. |
| add notification trap | add a Trap server for receiving alarms. |
| add smtp_server general | add an email sending server. |
| change alarm clear | clear alarms from the storage system. |
| change alarm_level | change the severity of a specified alarm. |
| change alarm_mask | mask specified alarms. |
| change alarm_object_mask | mask alarms of specified objects. |
| change event_config | configure the health check policy of the storage system. |
| change event_restore address | configure dump addresses for system logs. |
| change event_restore enabled | enable or disable the policies for dumping events. |
| change notification email | enable the email notification function and configure alarm and event notification mailboxes. Use this command if you want to enable the storage system to automatically send notification emails of the following to a specified mailbox: all alarms and the events with the email notification function enabled. |
| change notification email_extend | enable the email notification function and configure alarm and event notification mailboxes. Use this command if you want to enable the storage system to automatically send notification emails of the following to a specified mailbox: all alarms and the events with the email notification function enabled. |
| change notification event | set the switch of event notifications using a Trap server, SMSs, and emails. |
| change notification sms | set the switch of alarm and event notifications by SMS messages. Use this command if you want to enable the storage system to automatically send SMS messages of the following to a specified phone number: all alarms and the events with SMS message notification enabled. |
| change notification syslog | set the syslog alarm notification function. |
| change notification trap | change the settings of the trap server. Run this command if you want to change the settings of a trap server for receiving alarms. |
| change smtp_server config | configure the email-based alarm notification function. If you want to enable the storage system to automatically send an alarm notification email to a specified mailbox when an alarm is generated, run this command. |
| change system client_name | modify the address information about the storage system maintenance terminal. |
| change user_auth_email_server | modify configurations of the two-factor authentication email server. |
| create alarm test | simulate the reporting of fault alarm. |
| delete file | **delete file**s of a specific type from the system memory or system disk, where the files to be deleted have been exported before. |
| delete notification trap | delete a trap server. |
| export event | export logs, key logs, Call Home data, event information, diagnostic files, disk enclosure logs, FTDS statistics, or disk data destruction reports of a storage system. |
| remove notification receiver | remove email addresses or phone numbers used to receive alarm or event notifications. |
| remove smtp_server general | delete an email sending server. |
| show alarm | query system alarms. |
| show alarm_mask | query information about masked alarms. |
| show alarm_object | query alarm object information. |
| show event | query the events generated by the storage system. |
| show event_config | query the health check policy of the storage system. |
| show event_restore | query the configuration policies for dumping event. |
| show file export_path | export system data to a directory in the storage system and show the directory to users. |
| show file notification | check the path of the exported temporary files. |
| show file package_result | check the file exporting status. |
| show notification email | query the settings of the email-based alarm and event notification functions. |
| show notification email_extend | query mailboxes used for sending and receiving alarms and events. |
| show notification event | query the settings of event notifications using traps, short messages, and emails. |
| show notification receiver | query the mailboxes used to receive alarm and event emails, or the mobile phone numbers used to receive alarm and event short messages. |
| show notification sms | check the settings of the SMS-based alarm and event notification function. |
| show notification syslog | query the settings of SYSLOG notification. |
| show notification trap | query the settings of the trap server. |
| show smtp_server general | query the settings of the email-based alarm notification function. |
| show user_auth_email_server general | query configurations of the two-factor authentication email server. |
| test smtp_server general | test the connectivity of an SMTP server. |
| test user_auth_email_server | test the connectivity of two-factor authentication email server. |
