# show bst configuration


##### Function

The **show bst configuration** command is used to check the BST switch status.

##### Format

**show bst configuration**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Check the BST configuration.

```text
admin:/>show bst configuration
Enabled : Yes
```

##### System Response

The following table describes the parameter meanings.

| Parameter | Meaning                |
|-----------|------------------------|
| Enabled   | Whether to enable BST. |
