# add lun_group lun


##### Function

The **add lun_group lun** command is used to add LUNs to a specified LUN group.

##### Format

**add lun_group lun** { lun_group_id=? \| lun_group_name=? } { lun_id_list=? \| lun_name_list=? } { host_lun_id_list=? \| host_lun_id_start=? } { froce=? } \[ \[ async_replication_remote_id_1=? \] \[ async_replication_remote_id_2=? \| sync_replication_remote_id=? \| hyper_metro_remote_id=? \] \] \[ remote_name_rule=? \] \[ name_prefix=? \] \[ name_suffix=? \]

**add lun_group lun** { lun_group_id=? \| lun_group_name=? } { lun_id_list=? \| lun_name_list=? } { host_lun_id_list=? \| host_lun_id_start=? } { froce=? } \[ sync_replication_remote_id=? \[ async_replication_remote_id_1=? \] \] \[ remote_name_rule=? \] \[ name_prefix=? \] \[ name_suffix=? \]

**add lun_group lun** { lun_group_id=? \| lun_group_name=? } { lun_id_list=? \| lun_name_list=? } { host_lun_id_list=? \| host_lun_id_start=? } { froce=? } \[ hyper_metro_remote_id=? \[ async_replication_remote_id_1=? \] \] \[ remote_name_rule=? \] \[ name_prefix=? \] \[ name_suffix=? \]

##### Parameters

| Parameter | Description | Value |
|---|---|---|
| lun_id_list=? | ID list of LUNs or snapshots that you want to add to a LUN group. | To obtain the LUN ID list, run "show lun general". To obtain the snapshot ID list, run "show snapshot general". If multiple LUNs or snapshots need to be added to a LUN group: <br>Separate the LUN or snapshot IDs with commas (,). For example, "lun_id_list=1,2,3,4,5".<br>Specify LUN or snapshot ID ranges and separate the ranges with hyphens (-). For example, "lun_id_list=1-5,7,9-11". |
| lun_name_list=? | Name list of LUNs or snapshots added to a LUN group. | To obtain the LUN name list, run "show lun general". To obtain the snapshot name list, run "show snapshot general". If multiple LUNs or snapshots need to be added to a LUN group, separate the LUN or snapshot names with commas (,). For example, "lun_name_list=lun1,lun2,lun3,lun4,lun5". |
| lun_group_id=? | ID of a LUN group to which you want to add LUNs. | To obtain the value, run "show lun_group general". |
| lun_group_name=? | Name of a LUN group to which you want to add LUNs. | To obtain the value, run "show lun_group general". |
| host_lun_id_list=? | Host LUN ID that is assigned to a specified LUN. | The value contains one or more matches between LUN IDs and host LUN IDs. The format of a match is "LUN ID:Host LUN ID". If there are multiple matches, separate them with commas (,). Run the "show host lun" and "show host snapshot" commands to query the host LUN IDs that have been assigned. A LUN ID ranges from 0 to 65535, and a host LUN ID ranges from 0 to 4095. A maximum of 1024 matches are supported. |
| host_lun_id_start=? | Start value of a host LUN ID that is allocated to a LUN. | Run the "show host lun" and "show host snapshot" commands to query the host LUN IDs that have been assigned. A host LUN ID ranges from 0 to 4095. |
| force=? | Whether to perform a consistency check for HyperMetro host LUN IDs. This parameter is not specified by default. In this case, a consistency check for HyperMetro host LUN IDs is performed. | The value is "true", indicating not to perform a consistency check for HyperMetro host LUN IDs. |
| async_replication_remote_id_1=? | ID of the remote device for creating the first asynchronous replication pair. | To obtain the value of this parameter, run "show remote_device general" on the local device. |
| async_replication_remote_id_2=? | ID of the remote device for creating the second asynchronous replication pair. | To obtain the value of this parameter, run "show remote_device general" on the local device. |
| sync_replication_remote_id=? | ID of the remote device for creating a synchronous remote replication pair. | To obtain the value of this parameter, run "show remote_device general" on the local device. |
| hyper_metro_remote_id=? | ID of the remote device for creating a HyperMetro pair. | To obtain the value of this parameter, run "show remote_device general" on the local device. |
| remote_name_rule=? | Naming rules of remote resources. | The value can be: <br>"automatically_generated": The name is automatically generated by the system.<br>"same_as_locally": The name is the same as that of the local resource.<br>"user_defined": The name is defined by the user. |
| name_prefix=? | User-defined name prefix. This parameter is available only when "remote_name_rule=?" is set to "user_defined". | The value contains 1 to 32 ASCII characters, including digits, letters, underscores (_), hyphens (-), and periods (.), and must start with a digit or letter. |
| name_suffix=? | User-defined name suffix. This parameter is available only when "remote_name_rule=?" is set to "user_defined". | The value contains 1 to 16 ASCII characters, including digits, letters, underscores (_), hyphens (-), and periods (.). |

##### Usage Guidelines

-   A maximum of 4096 LUNs can be added to a LUN group.
-   If the LUN group is not in the protection group, remote_name_rule, name_prefix, and name_suffix do not need to be delivered.

##### Example

Add the LUN whose ID is "2" to the LUN group whose ID is "2".

```text
admin:/>add lun_group lun lun_group_id=2 lun_id_list=2
Add LUN 2 to lun group successfully.
```

Add the LUN whose name is "lun1" to the LUN group whose name is "lun_group1".

```text
admin:/>add lun_group lun lun_group_name=lun_group1 lun_name_list=lun1
Add LUN lun1 to lun group successfully.
```

Add the LUN whose ID is "5" to the LUN group whose ID is "3" that belongs to a protection group.

```text
admin:/>add lun_group lun lun_group_id=3 lun_id_list=5
Adding LUNs to PG or LUN group (lg03) in background.
Run the "show task general task_id=10" command to query the execution result.

admin:/>show task general task_id=10
Task ID    : 10
Task Name  : addluntogroup
Duration   : 0 day(s),0 hour(s),0 minute(s),3 second(s)
Start Time : 2019-09-20/10:28:17 UTC+08:00
End Time   : 2019-09-20/10:28:20 UTC+08:00
Process    : 100%
Status     : success
Object     : lg03
```

Add LUNs whose IDs are 0 to 4 to the LUN group whose ID is "0" and specify the start host LUN ID to "5".

```text
admin:/>add lun_group lun lun_group_id=0 lun_id_list=0-4 host_lun_id_start=5
Add LUN 0 to LUN group successfully.
Add LUN 1 to LUN group successfully.
Add LUN 2 to LUN group successfully.
Add LUN 3 to LUN group successfully.
Add LUN 4 to LUN group successfully.
```

Add LUNs whose IDs are 1 to 4 to the LUN group whose ID is "0". Specify the host LUN IDs of the LUNs whose IDs are"1" and "2" to "3" and "5", respectively.

```text
admin:/>add lun_group lun lun_group_id=0 lun_id_list=0-4 host_lun_id_list=1:3,2:5
Add LUN 0 to LUN group successfully.
Add LUN 1 to LUN group successfully.
Add LUN 2 to LUN group successfully.
Add LUN 3 to LUN group successfully.
Add LUN 4 to LUN group successfully.
```
