# show windows_group count


##### Function

The **show windows_group count** command is used to query the number of Windows groups.

##### Format

**show windows_group count**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the number of Windows groups.

```text
admin:/>show windows_group count

Number : 2
```

##### System Response

The following table describes the parameter meanings.

| Parameter | Meaning                     |
|-----------|-----------------------------|
| Number    | Quantity of Windows groups. |
