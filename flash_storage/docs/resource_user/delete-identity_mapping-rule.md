# delete identity_mapping rule


##### Function

The **delete identity_mapping rule** command is used to delete the identity_mapping rule.

##### Format

**delete identity_mapping rule** id=?

##### Parameters

| Parameter | Description | Value                                                           |
|-----------|-------------|-----------------------------------------------------------------|
| id=?      | Rule ID.    | The value is an integer ranging from 1 to 18446744073709551615. |

##### Usage Guidelines

None

##### Example

Delete the identity_mapping rule.

```text
admin:/>delete identity_mapping rule id=0

Command executed successfully.
```

##### System Response

None
