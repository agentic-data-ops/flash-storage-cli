# show windows_user count


##### Function

The **show windows_user count** command is used to query the number of Windows users.

##### Format

**show windows_user count**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the number of resource users.

```text
admin:/>show windows_user count

User Count : 2
```

##### System Response

The following table describes the parameter meanings.

| Parameter  | Meaning                    |
|------------|----------------------------|
| User Count | Quantity of Windows users. |
