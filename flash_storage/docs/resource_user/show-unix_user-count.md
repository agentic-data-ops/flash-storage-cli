# show unix_user count


##### Function

The **show unix_user count** command is used to query the number of UNIX users.

##### Format

**show unix_user count**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the number of UNIX users.

```text
admin:/>show unix_user count

Number : 2
```

##### System Response

The following table describes the parameter meanings.

| Parameter | Meaning               |
|-----------|-----------------------|
| Number    | Number of UNIX users. |
