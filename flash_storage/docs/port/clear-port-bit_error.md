# clear port bit_error


##### Function

The **clear port bit_error** command is used to clear the bit_error of the port.

##### Format

**clear port bit_error**

##### Parameters

None

##### Usage Guidelines

Before you perform this operation, ensure that all bit errors of the port are cleared.

##### Example

Clear port bit_error.

```text
admin:/>clear port bit_error
WARNING: You are about to clear bit errors of all the ports.
Suggestion: Before performing this operation, ensure that the bit errors of all the ports can be cleared.
Have you read warning message carefully?(y/n)y
Are you sure you really want to perform the operation?(y/n)y
Command executed successfully.
```

##### System Response

None
