# show dsm partition_status


##### Function

The **show dsm partition_status** command is used to query the DSM partition status.

##### Format

**show dsm partition_status**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the DSM partition status.

```text
admin:/>show dsm partition_status

Partition Status: Normal
```

##### System Response

The following table describes the parameter meanings.

| Parameter        | Meaning           |
|------------------|-------------------|
| Partition Status | Partition status. |
