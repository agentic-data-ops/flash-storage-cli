# delete isns server_ip


##### Function

The **delete isns server_ip** command is used to delete the IP address of the Internet Storage Name Service (iSNS) server.

##### Format

**delete isns server_ip**

##### Parameters

None

##### Usage Guidelines

-   Running this command prevents the storage system from obtaining target information by using the iSNS server.
-   Before running this command, ensure that the selected iSNS server is normal.

##### Example

To delete the IP address of the iSNS server, run the following command:

```text
admin:/>delete isns server_ip
Command executed successfully.
```

##### System Response

None
