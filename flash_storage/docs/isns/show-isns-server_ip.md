# show isns server_ip


##### Function

The **show isns server_ip** command is used to query the IP address of the Internet Storage Name Service (iSNS) server.

##### Format

**show isns server_ip**

##### Parameters

None

##### Usage Guidelines

None

##### Example

Query the IP address of the iSNS server.

```text
admin:/>show isns server_ip

ISNS Server IP : 192.168.43.5
```

##### System Response

The following table describes the parameter meanings.

| Parameter      | Meaning                                     |
|----------------|---------------------------------------------|
| ISNS Server IP | IP address of the iSCSI domain name server. |
